Admin decrypt tool

Works fully offline. Nothing you enter or open here leaves this page.

Open an export

Use this every time a reader sends you a .xlsx.enc file.

Create your key (do this once)

Choose a passphrase of at least 12 characters. The tool makes a private key file protected by that passphrase, and a public key to place in the app.

Keep the downloaded .key.json file and the passphrase in two separate safe places, and keep a second copy with another trusted officer. If both are lost, every export is permanently unreadable. Never put the key file on a reader's phone or in the app repository.
